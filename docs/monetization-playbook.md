# Monetization Playbook - qwen-pilot

This file is a commercial planning artifact, not a guarantee of revenue. Use it to make the repository legible as a sellable product, pilot, workshop, license, or proof-of-value package.

## Commercial Lane

- **Lane:** B2B developer automation
- **Primary buyer:** Developer-tool builders and teams standardizing Qwen CLI agent usage.
- **Revenue wedge:** Qwen-focused orchestration harness with typed workflows, prompts, and team coordination.

## Offer Ladder

1. **Internal automation harness** - pricing hypothesis: $1k-$5k setup
2. **Workflow template library** - pricing hypothesis: $8k-$25k rollout
3. **Agent-ops setup engagement** - pricing hypothesis: $1k-$5k/month workflow maintenance

## Acquisition Channels

- Qwen ecosystem content
- CLI demos
- Korean/English developer docs

## Proof Gates Before Selling

- npm run verify passes
- qp doctor path is documented
- Fixtures are deterministic

## Risk Boundaries

- Provider-specific behavior isolated
- Customer secrets stay local
- Human approval required

## 30/60/90 Day GTM

- **30 days:** Publish 3 Qwen workflow demos
- **60 days:** Create onboarding guide
- **90 days:** Offer team setup

## Metrics That Matter

- Workflow success
- Prompt reuse
- Review handoff quality

## Positioning Note

Lead with the specific operational pain, then show the runnable proof, then offer a narrow pilot. Do not pitch the repository as a vague app; pitch it as a concrete workflow with evidence, risk boundaries, and a next buying step.
